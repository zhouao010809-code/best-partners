# 最佳拍档自动任务接入

用户已确认接入最小闭环：交任务 → 看进度 → 回答问题 → 收结果。

## 实现边界

- 当前产品为 `xiaozhao-brain-console`，实现工作树 `desktop-read`。旧 `content-dashboard` 不是本次目标。
- 在个人版新增 `/autoloop`「自动任务」入口，沿用现有导航、视觉、HTTP session 与 CSRF。
- Fastify 代理 `/api/v1/autoloop/tasks`，凭据只由后端从本机 Autoloop 读取。前端不提供 Agent、目录、命令、权限或服务地址。
- 按当前资料库隔离任务映射，执行目录在应用私有状态目录。结果先展示，不自动归档、入库或外发。
- Autoloop 负责队列、并发、执行、问答续跑与重试；最佳拍档仅保存稳定任务映射并投影状态。关闭 App 不取消任务。
- 提交任务写可信规则，先确认热加载成功，再用固定事件 ID 发事件；失败重试不产生第二个任务。
- 专用 Codex/edit Agent，禁止复用可能为 full 的配置。状态与卡片只暴露本应用任务，不能转发包含完整规则的 why 响应。
- 开放提问显示等待回答；轮询断线显示进度暂不可读，不把它冒充执行失败。

## 分工与验收

1. 后端：共享契约、服务、路由、runtime 接线；用临时配置与假 HTTP 先写行为测试。
2. 前端：任务表单/列表/详情/回答/停止；覆盖空态、断线、幂等重试与状态刷新。
3. 集成：架构边界、类型检查、相关回归；临时资料库 Electron 真页面测试。
4. 打包：验证产物与源码一致；真实 Codex 只运行无业务数据的小任务，核对提问到完成。

## 验证约束

自动测试不使用真实资料库、密钥、通道或 Agent。既有提炼、归档、入库确认流程不变。

# 最佳拍档完整自动化接入

用户在 MVP 范围核对后明确要求“全部接通”，本轮据此直接实施。Autoloop 内核和无前端边界保持原样；全部客户端及适配属于最佳拍档。

## 可操作范围

1. 我的任务：选择独立目录、当前大脑或已绑定项目，选择本机 Agent、模型和已安装 Skill；任务输出保存在独立目录，资料目录只读，问题与结果回到最佳拍档。
2. 自动规则：读取和修改原生规则，设置定时或事件，启停、删除、手动触发；复用中台队列与并发，不另造调度器。
3. 连接与执行：Agent、来源、通道等原生配置，凭据专用只写入口，连接探测与服务重启。真实外部账号需要的登录、回调与接收方按实际状态呈现。
4. 运行总览：全局运行、卡片、费用、翻页、回答、结案、停止及脱敏追溯。
5. 场景模板：列出原生 recipes，读取内容并带入配置编辑，保持待配置状态，不自动猜测业务目标或启用外发任务。

## 数据与边界

所有本地配置写入共用同一文件锁；完整配置使用版本指纹防止并发覆盖；原生校验器校验后原子落盘。前端传来源 ID，服务器解析真实绑定路径，不允许任意路径注入。任务创建保存执行快照和稳定事件身份，重试不重复派单。密钥不进入响应或运行追溯。已授权的配置保存与真实外发是不同动作，探测不发送测试消息。

## 验收

先验证选择失效、重试改变配置、配置冲突、密钥脱敏、规则与真实状态一致等失败路径。随后跑类型和架构检查、相关后端与组件测试、隔离大脑的首次使用及自动任务开发/打包 Electron 流程。用最新构建替换 Downloads 预览并验证实际重开；原 Applications 安装保留。外部缺项按证据列出，不以配置入口代替已完成连接。

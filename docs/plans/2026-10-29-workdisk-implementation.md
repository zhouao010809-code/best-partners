# 本地工作盘实施计划

用户已确认并要求基于当前骨架执行。目标是让日常文件在工作台内完成收纳、浏览和找回，实际文件继续保存在普通本地文件夹。

## 已确定的产品边界

- 知识库继续承担长期可复用资料与学习笔记；工作盘单独连接普通文件夹。
- 选择日期后导入文件，自动建立 `YYYY-MM-DD/视频、音频、图片、文档、其他`；复制原件，同名另存，不覆盖。
- 现有目录按实际文件展示，不迁移、不重新分类旧文件。日期取有效日期目录，其他文件使用修改日期。
- 工作盘提供日期浏览、分类卡片、文本/图片/音视频预览、直接写文案，以及跨日期搜索。
- 搜索先理解用户的日期、文件类型和主题，再检索真实文件名、路径和支持的正文。AI 仅解释查询，不接收整盘资料；未配置时使用本地查找并明确提示。
- 本版视频、录音按文件信息查找，不宣称已理解声音或画面。文件删除、批量重命名、自动知识提炼不在此版本内。

## 实施步骤

1. 本地存储服务：独立绑定状态、根目录身份验证、限量扫描、复制导入、文案保存、来源片段与路径验证。
2. 桌面连接：受限原生选择器、拖放导入、受控预览协议、打开文件；与大脑目录隔离。
3. 查询理解：日期/类型本地解析，已有模型连接下的查询扩展，失败与取消处理。
4. 工作盘界面：常驻入口、收纳日期、类型筛选、跨日期搜索、预览和保存文案。沿用深色视觉与绿色交互强调。
5. 验证：隔离临时目录测试真实读写、重名保护、目录边界；组件验证搜索与保存状态；桌面走查验证接入、保存、预览、查找及 720px 布局，复跑首次使用走查。

# 工作盘便捷性改进

用户已认可当前评估与改进顺序。沿用现有工作盘与独立知识库，不移动历史文件。

## 交付行为

1. 手动收纳默认跟随本机今天，跨午夜、唤醒后更新；用户明确选择历史日期时保持选择，并可一键改回今天。实际开始导入时重新取得默认日期，异步完成反馈使用此次提交的日期。
2. 工作盘首屏前置搜索和收文件入口；缩小介绍区域，自动收纳显示紧凑状态，设置和完整回执可展开，失败/等待不被折叠隐藏。最近文件按修改时间倒序，保留日期与类型筛选。
3. 图片与视频卡片显示按需加载的真实本机缩略图。身份校验与切盘失效沿用受限桌面访问，生成失败回到类型图标。
4. 在已有文本搜索基础上，补本机图片文字与 PDF 文字层搜索，结果保留正文片段。读取、超时、缓存和处理数量有界；未完整读取明确反馈。不新增外发资料或音视频转写服务。

## 实施和验证

- WorkdiskPage / 日期 hook：先用隔离时钟复现跨日错误，验证跟随今天、历史日期保持、导入提交时间与结果对应；重排主区域和卡片标题。
- WorkdiskAutoCollection：保留异步设置保存和失败恢复语义，调整独立组件测试及桌面展开操作。
- 桌面缩略图：复用已有本地文件校验，用合成图片/视频验证格式、真实像素、越界拒绝和失效。
- 本地内容检索：复用文字提取组件，验证匿名文件名的 PDF/图片正文命中、缓存更新、读取范围与失败提示。
- 集成后 typecheck/build/package，开发版和打包版工作盘/自动收纳/命名/首次使用回归。宽窗口及 720px 视觉复查。所有写入测试仅用临时目录。

## 依据

- 用户当前确认的“保存后不用操心，按记得的内容找回来”与此前工作盘实施计划。
- 当前实际界面观察：搜索在长收纳区域之后、卡片无内容封面、跨日手动收纳日期未自动更新。
- 大脑《AI应用落地的四个核心要素》中的稳定工程实现，用于可靠性优先；首次使用走查规则用于状态、返回路径与隔离验证。

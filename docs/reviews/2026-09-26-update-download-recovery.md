# 应用更新下载恢复验收 · v0.1.6

## 已观察

- 原安装包下载退回 Node fetch，没有使用 Electron 的系统代理。用户界面停在 0% 后极慢增长；不足 1% 的字节被整数百分比隐藏。
- 同一官方资产取首 1 MiB：直接连接 20 秒无响应，使用当前系统代理约 2.33 秒完成。隔离 Electron 默认会话实际解析到系统代理，约 2.47 秒完成。
- 修复后的生产下载函数配合真实 Electron Chromium 传输，从官方 GitHub 完整下载 v0.1.5 的 207,723,100 字节 DMG，约 31.17 秒完成，SHA-256 与官方资产一致。此速度只代表本次网络实测。
- 版本检查保留原先可用的 JSON 查询通道；本机代理出口对 GitHub API 的匿名请求出现 403 限流，故未将查询切换到代理网络。下载采用 net.request 的手动重定向适配器，验证每一跳后才连接，不绕过 TLS 或域名限制。直接使用 net.fetch(manual) 会取消重定向，故不适用于此下载循环。
- 连接、首字节及中途无数据进展各有 30 秒期限，保留 15 分钟总期限。显示连接状态、已下载字节和细分百分比；失败可重试。取消和所有失败出口停止请求、清理临时文件。

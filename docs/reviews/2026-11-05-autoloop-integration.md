# 自动任务接入验收

实现工作树：`desktop-read`；基线提交 `3d1d2c1`。本次为本地预览构建，没有发布或替换已安装应用。

## 行为

- 个人模式新增“自动任务”：提交、进度、问题回答、停止和完整文本结果。
- 任务按资料库身份隔离；固定私有执行目录与本机 Codex/edit Agent。凭据只在 Fastify 后端读取。
- 规则在中台可见后才发固定 ID 事件；响应丢失与重启可恢复原任务，未派发任务可在页面重试。
- 开放 ask 优先显示等待；notice 只显示消息；轮询失败不冒充执行失败。
- 停止撤销后续规则、关闭自有卡片、停止可取消的运行。中断时保持可重试状态，unknown 不冒充已停止。
- 结果安全显示为文本。尚未自动读取真实知识库、自动归档、写项目或外发。

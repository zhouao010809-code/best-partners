# App 内选段学习助手验收 · 2026-10-12

状态：用户批准的第一版已实现并完成隔离自动化验收。此记录区分已观察、设计推断与未验证；自动化通过不表示真实用户已经理解文章。

## 已观察

- 原始资料、知识库、提炼队列的已加载正文支持选段；身份与版本来自正文读取结果，元信息、未提交候选、跨区、刷新中及失败的正文不能建立新引用。6000 Unicode 码点完整保留，超限提示缩小。
- 选段只打开问问并填入草稿，点击发送才调用模型。独立引用卡保留原句、标题与版本；每条消息保存当时快照。同文同版本可换选段；换文或换版本进入新学习会话；普通历史及未发送问题保留。
- 服务端按会话固定学习用途、资料路径及版本；省略字段不能解锁。仅注册 `search_knowledge`、`search_materials`、`read_document`，均限定当前文档；发送及读取重新核对版本。实际证据与选文快照分别保存。
- 学习回答提供“说简单点”“举个例子”及自由追问；“保存理解”须编辑确认。数据库迁移 025 独立保存学习笔记，服务端根据实际大脑身份隔离；稳定 UUID、版本冲突与幂等重试均验证。
- 已展开列表在保存后刷新；来源更新、回收、缺失时保留快照并说明状态。笔记保存不依赖来源或会话记录继续存在。数据库关闭重开仍可找回。
- 独立审查复现了“移除引用仍能重试发送旧选文”，已修复；静态审查发现关闭面板/继续追问卸载笔记编辑区，已用运行内草稿缓存和稳定挂载修复并补回归。
- Electron 开发版和本机打包版均完成：合成文章划选 → 固定模型读取当前资料并解释 → 快捷追问 → 编辑理解 → 关闭重开面板保留编辑 → 保存 → 退出重启 → 资料下找回笔记与问问历史。
- 桌面流程断言点击发送前模型调用为零、两轮只提供三个读工具、重启后两轮历史与原句恢复；原文和正式知识哨兵字节不变。宽屏与 720px 窗口截图检查通过，引用和按钮可换行，编辑区可滚动。
- 复查首次使用规则：开发/打包、空大脑/已有待处理资料 4 种零配置路径通过；新学习入口没有添加首次使用前置配置，仍沿用现有模型设置。

## 设计推断

将引用、问题、解释和学习笔记放在阅读场景中，有望减少复制切换；只读范围和逐条快照让用户更容易核对回答出处。这些为设计判断，不是已经测得的学习效果。

## 未验证与本期边界

- 未调用真实付费模型，未使用真实用户资料、密钥或账号。解释是否清楚、阅读效率和理解提升仍需真实试读。
- 本次未做 Developer ID 签名、Apple 公证、DMG 发布或全套 release gate；打包通过不等于公开发布完成。
- 笔记保存于本机 App 数据库；仅复制大脑 Markdown 目录不包含它们。未确认保存的内容不承诺 App 重启恢复。原文回收后的状态由集成/组件验证，完整 GUI 回收再恢复笔记路径未另做真人走查。
- 首版支持笔记创建、查看和编辑。笔记放弃/回收/撤销/恢复、批量管理、导出及正式知识转化均未实现；未保存编辑可不执行确认保存。当前列表不是完整笔记管理工作台。
- 回源打开全文；不承诺逐字高亮。没有浏览器跨页面选文、PDF 画布选段或 OCR。现有个人只读 STDIO MCP 保持原契约，不读取这些学习笔记。

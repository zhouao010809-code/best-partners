# 项目与 Skill 分类批量整理 · 2026-09-27

## 问题与改动

0.1.7 的恢复路径仅面向单条操作，清理多个选题、脚本或自定义分类时仍需反复点击确认。本次在原有回收范围内增加可访问的勾选框、全选当前列表、已选数量、一次确认批量回收、整批撤销及回收站多选恢复。

- 项目覆盖创作台、选题库、已定稿及项目回收站。切换项目或列表清除选择；刷新剔除不再可操作的项。批量确认冻结所选 ID 与 revision，未选内容不随之后的列表变化被加入。
- Skill 覆盖个人自定义分类，排除未分类、全局与公司目录。每个目录均经过原有完整树快照预览，再确认整个范围；过期预览必须显式重新核对。
- 操作串行执行、逐项显示结果。部分失败保持失败项选择和具体原因，成功项可恢复；不把部分失败包装成事务回滚或全部成功。
- 整批撤销只恢复本次成功项。项目使用成功回执中的 revision，拒绝撤销后来被修改的版本；单条恢复只移除对应撤销成员，不丢失其他成员。
- 项目响应丢失会只读核对恰好一次状态转换、正文与 revision；无法确认时不重试写入、不虚报成功。Skill 响应未确认时提示刷新持久回收站核对，不纳入已确认成功数。
- 操作期间禁用交错编辑、选择与局部导航。离开整个页面会停止尚未发送的操作；已经完成的回收仍由原有持久记录恢复。
- Skill 预览容量支持完整 1000 分类列表，5000 个待确认令牌达到上限后拒绝新增，保留旧令牌。查找目标分类只检查服务端已发现的目录名及目标内容，避免每预览一个分类都重新扫描所有分类。根目录、目录身份、树快照和恢复重名校验保留。

## 验证方式

组件回归覆盖选择范围、全选/取消、一次确认取消、部分失败重试、整批撤销、批量恢复、双击、局部导航、离开页面、过期预览和响应丢失。目录服务覆盖 1000 目录预览与令牌容量。新增 Electron 开发版和打包版场景使用隔离大脑、项目及 userData，选择两条并保留一条，验证取消、回收、撤销、重启恢复、同名冲突与原始字节保真；同时记录 1360 / 720 宽度截图。

## 设计推断与边界

勾选与批量工具条可减少重复整理操作；这是设计判断，尚未进行独立真人可用性研究。项目源文件、已有导出文件、统一资料回收站逐项永久删除及公司权限不在本次改动范围。回收操作没有多条原子提交保证，界面明确汇报逐项结果。测试不调用真实付费模型，不试删用户真实资料。分发仍沿用未签名、未公证的手动安装预览包。

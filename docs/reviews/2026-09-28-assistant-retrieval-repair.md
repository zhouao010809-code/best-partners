# 问问检索修复验收 · 2026-09-28

## 修复结果

已有可读资料会因范围切换、整串关键词匹配及项目引用路径不一致而漏搜或读失败。本次沿用现有数据和权限，修复这三处链路。

- 项目 → Skill 库 → 项目保留原问问范围和草稿；进入大脑全局页面退出项目上下文，换项目仍隔离。新项目对话首次持久化即绑定项目和版本。
- 标题、允许的召回字段及项目已解析正文支持中文词边界和多词匹配，要求全部词命中，直接标题/文件名优先。全局知识仍不搜索正文、路径或来源链接。普通浏览维持原路径顺序，搜索分页使用相关性顺序的稳定锚点。
- 项目正文读取兼容同项目搜索引用与相对路径；不解码、不规范化用户路径，拒绝跨项目、绝对路径和穿越。编辑提案保持仅相对路径。
- 搜索工具区分查询匹配数、返回文件数和本次不支持解析数；模型收到项目总文件量与可读量，不应再把一页搜索结果当成整个索引。全局模式明确不包含项目文件。

## 验证边界

测试使用内存数据库与临时大脑、项目、userData，不以真实账号调用模型。真实索引只做只读检索比对，不改原资料、知识笔记或对话数据。模型是否在每次真实回答中正确选择关键词仍属于模型行为，不能据确定性工具测试宣称已验证所有生成结果。

本次是本地关键词召回，不包含向量/语义服务；不承诺任意口语句命中。DOCX/XLSX/HTML/RAR 等解析能力未扩展，不支持的正文继续明确标记为未解析。项目 5000 条候选上限属于既有行为，本轮未扩大。

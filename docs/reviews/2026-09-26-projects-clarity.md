# 个人项目界面易读化 — 0.1.3

## 问题与改动

项目页原先同时显示壳层标题、项目标题、连接卡、范围说明卡和多处项目名称；文件列表将目录与所有相对路径平铺，默认暴露隐藏文件；问问仍提供普通知识库的起步问题。用户难以判断从哪里开始。

此次按“进入项目 → 查看资料 → 问问这个项目 → 已保存产出”整理界面。保留单个页面标题，正常连接状态压缩为一行，异常重连操作保留。文件夹可展开，默认隐藏点文件，长文件名可换行；搜索显示命中的文件及目录位置。空产出页明确说明确认保存的入口。问问显示一次项目名，提供项目任务建议，点击建议只填草稿。

同时修复项目刷新后问问未重新绑定资料版本，以及首次读取失败后重试只恢复摘要、仍无法发送的问题。恢复保留草稿，重新发送仍由用户明确触发。项目 API、目录范围、确认写入契约未改变。

## 设计推断与边界

入口更少、目录层级和普通中文标签更容易理解属于设计推断，并非用户研究结论。文件列表仍按现有 API 最多读取 200 个条目，超出时说明限制；隐藏文件可手动显示。200 是条目上限，包含目录，不能解释为完整文件数。

所有自动验收使用合成临时资料和独立 userData，禁用真实模型发送。尚未配置 Apple Developer 签名和公证，因此仍为手动安装预览 DMG，不能宣称系统级自动安装已启用。

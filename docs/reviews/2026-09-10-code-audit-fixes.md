## 行为变化

| 问题 | 修复后的行为 |
|---|---|
| 编辑器取消退出后服务已关闭 | 窗口同意退出后才关闭服务；连续退出也会等待同一次清理完成。 |
| 多窗口互相覆盖、删除候选临时草稿 | 每个编辑器独立持久保存；复制标签页获得独立分支；仅清理当前编辑器拥有的草稿，其他副本可核对恢复。 |
| 同路径新资料混入已删除资料的候选 | 当前入库聚合应用与队列一致的删除分界；旧提炼记录仍可单独追溯。 |
| AI 失败后迟到候选落库 | 确定结束状态后，立即撤销本轮工具信号，再释放运行记录；失败、停止、超时、关闭均有隔离回归。 |
| 打开另一页导致原页面写入失败 | Bootstrap 重用有效会话；客户端对执行前的会话/CSRF 失效刷新认证并最多重试一次。 |
| 操作页连接恢复后停留在旧错误 | 连接/索引从不可用转为可用时重新读取，不依赖首次就绪时不存在的数据版本变化。 |
| 原生构建依赖固定 Node 缓存 | 根据运行 Node 版本检查头文件；支持自动准备缺失缓存和显式离线目录。 |

认证重试保留原请求内容、幂等键与取消信号；网络结果不明、服务器内部错误等不会自动重放。存储修复不回写历史资料，也不自动重算已经完成的历史批次。

# 项目问问保存后的资料同步 · 2026-09-27

## 范围与行为

用户确认的需求是：修改成功后，资料列表与当前正文自动刷新，并显示哪些文件已经保存。此次沿用已有项目保存流程，不增加多个文件联动修改或原文件覆盖入口。

- 仅服务端完成回执触发最近保存清单和自动刷新。最近 10 个路径按项目隔离、去重；待确认、失败、取消与单纯修改建议不会被标为已保存。
- 自动刷新保留搜索词、资料范围、已展开目录和当前正文。刷新时保留上次内容；失败明确提示未刷新并提供重试。连续保存与迟到响应不会重挂载资料面板或覆盖较新的结果。
- 已保存输出增量加入项目索引，立即可列出、搜索和读取，不因自动全量扫描使其他待确认计划失效。索引失败保留真实落盘回执与单独提示，幂等重试只修索引，不重复写文件。
- 全量刷新、重新连接与确认保存共用项目顺序锁，防止旧扫描覆盖新索引。对话中的项目写入卡片从持久化计划恢复状态。

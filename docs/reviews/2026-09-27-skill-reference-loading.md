# Skill 配套参考文档调用修复 · 2026-09-27

## 问题与行为

原调用链能确认并传入 `SKILL.md`，但目录只枚举直属 Markdown，模型也没有读取 `references/` 的工具。因此 jingwei 方法说明中的模板、流程和课程依据无法进入模型上下文。

现在详情页列出直属 Markdown 和 `references/` 中的配套文档；确认使用 Skill 后，本轮模型获得该 Skill 的目录及专用 `read_skill_reference` 工具。正文在模型请求对应文件后才返回，执行记录显示文件名及结果。普通下一轮不会继承此工具。

## 读取边界

- 工具绑定本轮确认的 Skill ID、主文档版本和参考路径快照；不能读其他 Skill、脚本或任意文件。
- 限制目录扫描、嵌套深度、路径长度与文件大小，拒绝符号链接、无效 UTF-8 和读取期间的身份变化。
- 每次最多 12000 字符，每轮最多 10 份文档、60000 字符；支持续读，拒绝拆开 Unicode 代理对的参数。并发请求预留预算，取消后拒绝读取结果。
- 文档仅为参考资料，不改变既有权限和写入确认规则。用户原始 Skill 文件未改写。

# Skill 库界面整理 · 2026-09-27

根据用户提供的桌面截图，收紧重复说明、过长卡片及常驻整理操作。保留应用现有深色样式和本地 Skill 数据契约。

## 实现

- 移除页内重复大标题面板，顶部直接提供名称/描述搜索、新建文件夹和刷新。
- 默认查看全部 Skill；保留未分类、自定义文件夹和独立的文件夹多选。搜索限定当前分类，切换分类或创建/恢复文件夹时清空搜索；查看详情后返回保留原查询并恢复查看按钮焦点。
- 卡片使用等高标题区、三行简介和底部查看入口；全文在详情中阅读，原始名称、描述与文件内容不改写。
- Finder 与移动操作收进右上角“更多操作”，支持点击外部、焦点离开、Escape 关闭。Escape 优先收起菜单，保留已打开的问问面板。
- 文件夹回收组件持续挂载，保留原有预览确认、忙碌锁定、撤销、批量恢复和失败项重试。

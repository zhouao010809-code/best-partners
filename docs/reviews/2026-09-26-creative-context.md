# 项目创作档案与资料选择验收 · v0.1.5

用户批准以项目资料驱动短视频选题与脚本创作，本轮聚焦可复用创作档案、每条参考范围及编辑界面。

## 已实现 / 源码确认

- 每项目独立保存受众、内容目标、表达风格、已确认事实及避免表达；档案默认收起。手工填写需明确保存，AI候选需预览、采用到表单、再保存。保存冲突保留当前填写。
- 最多3个本项目已定稿版本可固定为表达范例，不随新定稿漂移。档案及样稿不能充当工具权限，旧来源编号从生成上下文清除，避免与本轮证据重号。
- 每条稿件可自动找资料，或指定1–20份可读原始文件。范围随自动保存、版本、恢复、副本保留；策划选题继承请求提交时范围。所选模式只开放范围内搜索/读取，关闭全局知识工具，先验证全部所选文件，统一使用本轮字节快照。
- 项目文件阅读对同一验证过的字节计算SHA和解析文本，避免文件变更后的正文配上旧索引哈希。停止资料扫描保留原项目状态，立即重试可重新扫描。
- 当前稿、范围或档案变化会阻止采用旧建议；旧版本建议没有档案revision时按0处理。选题保存过程中档案变化会停止剩余保存，已经保存的条目保留。
- 写稿时压缩标题和资料状态，项目讨论与“打磨这篇”分开；保存版本不强制展开历史，定稿直接预览、确认导出。

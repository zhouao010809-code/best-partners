# AI 彩光交互实施计划

> 已被用户本轮明确要求替代：取消全窗口光层，仅保留问问入口与面板边框流光。当前实现与验收见 [产品 UI 实施计划](2026-09-10-product-ui-implementation.md)。下文保留为被替代的历史方案。

**目标：** 在已确认的黑银界面上加入用户要求的悬停彩光、任务启动光泽和运行边缘光。

**范围：** 问问入口、发送按钮、开始/重新提炼和确认发送按钮。默认把用户所说的旋钮理解为 AI 按钮；资料柜把手暂不扩展。保留现有确认、模型选择和数据流程。

**设计（按视觉反馈修订）：** 蓝紫为主、少量玫粉。控件使用两处融合的柔光与局部边缘反光，移除五色平移；窗口移除闭合亮边，改为顶部蓝光和底部蓝紫玫粉光源。启动时边缘柔光向内舒展一次，持续运行时以不同节奏缓慢漂移，完成后淡出。正文不模糊，光层不拦截点击。减少动态效果模式保留静态柔光，取消启动与循环动画。

**接入：** 使用共享 CSS；AppShell 只渲染一个装饰层，通过现有问问运行状态和工作台的真实 generating 标记激活。仅发送请求的提交阶段可提前激活，不将读取历史、设置刷新或预览标为 AI 正在运行。队列使用已有 generating 数量，不新增后端轮询。

- [x] 标记 AI 控件与真实提交/运行状态，避免普通操作触发任务光。

- [x] 在纯内存浏览器夹具中检查控件聚焦、发送、运行、停止、完成和关闭后继续；检查窄窗口无水平溢出。减少动态效果与高对比度分支已做代码检查，未切换系统偏好。真实预览只检查渲染，不调用模型。

**边界：** 问问任务关闭面板后继续显示运行光；提炼光反映当前打开的工作区所掌握的状态。切到不展示提炼状态的其他页面不会新增后台检测来维持光效。

## 柔光修订验证

- 本次仅修改共享 CSS，不调整任务状态与业务流程。静态模糊配合 transform/opacity 动画，光源具有尺寸上限。
- 纯内存 assistant 夹具实测悬停（DOM :hover 为 true）、启动、自动完成、手动停止。完成与停止后光层 opacity 为 0、visibility 为 hidden；pointer-events 为 none。
- 1270px 可视区检查启动光泽与文字可读性，无水平溢出。减少动态效果和高对比度分支经过代码复核，未切换系统偏好；未测量帧率。
- vite build --emptyOutDir false 通过，保留旧资源防止正在运行的服务引用失效；仅有既有大包提示。相关 142 项组件测试为首版接入结果，本次纯样式修订未重复运行。
- 实际 Electron 应用已重新加载构建；原提炼页面确认读取 blur(12px) 和新版径向光源，无控制台错误。运行光验证仅使用内存夹具，不额外调用模型。

# 问问资料入口实施计划

**Goal:** 让用户能看见上下文用量、开启与恢复对话、导入文本 PDF/MD/TXT，并以问问完成有来源的归档与候选提炼。

**Architecture:** 附件层负责本地原件、解析结果与归档映射；AssistantService 负责本轮选区、用量及允许的工具动作；现有归档/候选/入库事务保持写入真源。前端按真实服务状态显示用量、附件和任务回执。

**Tech Stack:** React / TypeScript / Fastify / SQLite / Electron / PDF.js / Vitest。

用户已批准设计完成后直接执行。保留现有工作区修改，不创建提交、不以真实大脑资料做测试写入。执行采用当前协作 Agent 的独立模块分工，根 Agent 负责契约、集成、复核与真实 UI 验收。

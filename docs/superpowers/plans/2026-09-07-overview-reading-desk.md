# 大脑总览 · 黑银阅读桌

## 已确认方向

总览延续黑银实体感：放大可读的材料牌堆，压缩统计，最近知识改为书签目录。保留现有数据与操作边界，不修改收件箱、提炼队列和回收站。

### 用户追加：侧向 3D 牌堆

最终澄清：用户要恢复最初的窄侧面、紧密叠放牌堆，不接受新版大卡片调斜。Dashboard 恢复 MaterialDeck 的 default 布局和原始 CSS，撤掉 dashboard 对牌面、透视及详情的覆盖；保留新版统计、知识目录和外围阅读桌。资料筛选与提炼交互不变。

## 实施

1. DashboardPage 使用独立作用域样式，单行统计、阅读桌、知识目录与真实导航。
2. MaterialDeck 增加可选 desk 外观布局；默认布局不变。少量牌保持标题可读，多牌可滚动，选中后仍为详情和有序侧牌。
3. 通过现有总览组件测试与牌堆测试；独立 API mock 浏览器场景验收空态、少牌、多牌、键盘、窄屏和只读边界。
4. 构建后仅更新桌面 App 的 client 资源；保留 server、electron、native，真实 App 只读检查后交付。

## 完成判据

- 总览牌堆仍仅显示符合条件的未提炼资料。
- 部分入库、已完成和移出队列的排除逻辑不变。
- 卡片可读、选择和返回焦点可用；知识条目可打开原路径。
- 页面不横向溢出；多牌溢出只发生在牌堆内。
- 不向真实资料发起提炼、归档、删除或其他写操作。

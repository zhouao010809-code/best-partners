# 产品 UI 与问问边框流光实施计划

**Goal:** 落实已审阅的产品 UI 改善；按用户本轮明确要求将流光限制在问问入口与对话框边框。
**Architecture:** 沿用 React、现有 API 和草稿/入库协议，按问问、提炼审阅、资料检索三个独立区域实施。首页与跨页入口在主流程统一集成。视觉状态由真实请求状态驱动。
**Tech Stack:** React / TypeScript / CSS / Fastify / Vitest。

用户已明确授权实施前述评审，不再重复请求设计审批；不提交既有混合工作区改动，不在真实知识库做测试写入。

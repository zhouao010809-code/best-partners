# 个人项目界面易读化

用户反馈“我的项目这个界面看不明白”。实际 0.1.2 界面重复展示壳层标题、工作区标题、连接卡、范围卡和问问范围，资料列表落到首屏下方，文件夹不可展开，长路径隐藏文件名。

本次在用户授权的页面优化范围内，保留现有项目读写与问问契约，重排列表、项目详情、资料浏览及项目问问的信息层级。使用现有 React、CSS 变量和图标，不新增依赖。

- 项目页面自行提供唯一主标题，壳层不再重复展示 PROJECT/READ ONLY 标题；保留侧栏、全局状态和可访问焦点。
- 列表明确“连接已有文件夹”，展示项目名称、可读资料数和连接状态，整行进入项目。选择文件夹、扫描、确认仍分步进行。
- 工作区标题显示项目名和打开项目问问的主动作；正常连接状态缩成一行，刷新统一叫“更新资料”；重连异常展示原因与下一步。
- 文件工作面使用“项目资料 / 已保存产出”；文件夹可展开，主行展示文件名，搜索显示目录与匹配结果。默认隐藏点开头的系统/配置路径，可显式显示；不改扫描范围或文件。
- 现有 API 单次最多 200 条，超过时明确提示搜索缩小范围；目录不冒充资料份数。搜索无结果、空产出、单侧读取失败分别反馈。
- 清除切标签/搜索/刷新后旧正文与迟到响应；真实 API 相对路径、解析限制不变。
- 项目问问只显示一次项目名，压缩范围说明，提供梳理重点、查找资料、起草计划的项目示例。示例仅填草稿，发送与保存仍由用户明确操作。
- 进入项目沿用现有问问上下文和自动打开行为，不打断历史/草稿，不改变 revision、重连、确认写入或原文保真约束。

验收：相关组件与壳层回归；隔离开发/打包项目绑定、资料展开/搜索/预览、产出空态、问问建议、刷新、720px 窄窗；首次使用 4 场景。所有演练使用合成文件和隔离 userData，不调用真实模型。按完整提交树打包，并验证本机实际安装包。

# 项目资料实时显示保存结果

用户已确认范围：在项目问问里保存成功后，资料列表与当前正文自动刷新，同时显示哪些文件已保存。无需用户逐个翻找核对。不增加多个文件联动改写能力。

## 交互与状态

- 保留当前范围、搜索词、展开目录和正在预览的文件；刷新不重挂载资料面板。
- 收到服务端完成回执后，展示“最近保存”清单，按项目隔离、按路径去重，最多保留最近 10 个文件。未完成、失败和取消不能进入已保存清单。
- 自动重新读取资料列表和当前正文。读取期间保留内容、显示更新中；失败时明确展示仍是上次内容，并提供重试。新请求替代旧请求，离开或切项目后不得被迟到结果覆盖。
- 最近保存列表与正文来自实际后端结果；不将模型声称完成视为落盘成功。

## 数据链路

项目问问仍通过既有确认流程创建 `AI工作区` 新文件。修复当前成功落盘后未更新文件索引的缺口：增量登记已确认输出，不触发源资料版本变化，也不让其他待确认计划失效。已完成回执先保留；索引同步失败单独报告，并可通过幂等确认修复，不能重复创建文件。

项目更新事件携带已完成的目标路径，页面传入刷新序号和最近保存路径，替代更换组件 key。原始项目资料的覆盖权限不变。

全量扫描、重新连接和输出确认共用每个数据库、每个项目的顺序锁，避免较早扫描的快照覆盖新保存输出的索引。对话重新读取时也需要从持久化的项目写入计划投影状态，不能让旧会话快照把“已保存”恢复为“待确认”。

## 验证

组件检查保留状态、失败重试、并发迟到响应、项目隔离与完成状态。后端验证确认后立刻可以列出和读取输出、另一待确认计划仍有效、原文件字节不变。隔离 Electron 开发版与打包版通过模拟模型生成保存计划，确认后验证真实磁盘与界面同步，复查首次使用入口。未用真实账号或资料进行写入测试。

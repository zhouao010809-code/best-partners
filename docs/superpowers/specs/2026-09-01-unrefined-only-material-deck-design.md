# 总览牌堆只展示未提炼材料

日期：2026-09-01  
状态：已确认

## 目标

大脑总览中的 MaterialDeck 只展示 `知识入库状态: 未提炼` 的材料。`部分入库` 不再出现在牌堆中，但仍属于总览统计与提炼队列的数据。

## 设计决策

过滤发生在 `DashboardPage` 的牌堆数据适配层：总览仍完整读取 `未提炼` 与 `部分入库` 材料，用于计算两类指标；传给 `MaterialDeck` 前，只把 `knowledgeStatus === '未提炼'` 的记录转换为卡片。

`MaterialDeck` 组件自身保持通用，不内置业务过滤规则。提炼队列、材料 API、总览的“部分入库”指标及其他页面均不改变。由于牌堆中的卡片全部为未提炼状态，其下一步动作统一为开始提炼。没有未提炼材料时，沿用 MaterialDeck 现有空状态。

## 数据流

1. 总览读取完整的待处理材料集合。
2. 指标分别统计 `未提炼` 与 `部分入库`。
3. 牌堆适配函数仅保留 `未提炼`。
4. MaterialDeck 渲染过滤后的卡片集合。

## 测试与验收

- 先增加回归测试，并确认当前实现会因“部分入库仍出现在牌堆”而失败。
- 当总览数据同时包含未提炼和部分入库材料时，牌堆区域只出现未提炼材料。
- 同一数据下，“部分入库”指标仍显示正确数量。
- 提炼队列仍可筛选并显示部分入库材料。
- 仅运行 MaterialDeck 的独立组件示例时，其通用能力不受影响。
- 组件测试、类型检查、生产构建和相关浏览器端到端测试通过。

## 非目标

- 不修改后端材料查询或 API 契约。
- 不改变部分入库材料的状态或文件内容。
- 不重设计牌堆视觉、动效或交互。
- 不修改正式大脑仓库。

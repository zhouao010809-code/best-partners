# 统一回收站设计

用户已确认：左侧栏底部唯一垃圾桶入口，独立页面；按删除发起位置分收件箱、原始资料、提炼队列、知识库四类；支持恢复与逐项彻底删除。视觉采用黑银磨砂金属桶、银色桶沿、四个分类隔片、纸页列表，选中后才显示详情与操作。沿用当前 App，不新增依赖、不迁移旧回收文件。

## 行为契约

- `/trash` 是唯一回收站浏览页面。旧 `/library?view=trash` 转向新页面；收件箱不再内嵌独立回收列表。各页仍保留删除按钮。
- 分类是删除发起入口，不是资料当前状态。`intake` 为整份收件箱资料，`library`、`queue` 为同一原始 Markdown 回收服务的不同入口，`knowledge` 为单篇知识 Markdown。
- 队列保留明确命名的“移出队列”（只隐藏）；新增“删除文档”（预览明确原文也被回收）。已有隐藏记录不自动转为文档删除。
- 删除知识笔记只处理选中 `.md`，不级联原文、附件、其他笔记、提炼历史；恢复原路径，原链接重新有效，不擅自回退入库状态。
- 单 Markdown 复用已有私有回收存储及日志；旧记录未带来源时按原始资料分类。新 intent 持久记录 origin，不修改旧不可变日志。
- 收件箱保留整包移动/恢复语义，新增带预览 token 的整包永久删除。预览显示文件数和字节，真正删除前校验对应 UUID、身份和确认范围；重启/普通查询或重试不自动继续永久删除。
- 文件同名冲突不覆盖。失败与中断可查询同一操作；恢复和永久删除不能同时执行。已完成恢复或永久删除不再算桶内数量。
- 原文/知识正在提炼或被未完成入库批次使用时，不允许产生冲突写入。永久删除原文后，队列历史不能让旧项回流；后来同名新文档不永久屏蔽。

## 页面

侧栏入口包含垃圾桶、文字和真实未恢复数量；有内容时纸页提示，悬停桶盖轻抬。主页面顶部标题、搜索和刷新，全部视图加四个来源隔片。内部深色凹面、银色桶沿，文件保持完整可读标题、原位置和回收时间。选择文件才展开详情；提供恢复和逐项彻底删除，不提供自动清空。窄屏单列，键盘可达，尊重减少动态效果设置。请求失败不能伪装为空桶。

## 验证

隔离临时仓库验证四个来源删除、重启保留分类、恢复原路径、永久删除、同名冲突、整包附件保真、历史不回流及知识入库写入互斥。组件测试覆盖入口、分类、错误和确认；浏览器检查桌面/窄屏。真实仓库仅做读取与页面打开检查，不为测试删除真实文件。

# 最佳拍档网页剪藏扩展

这是一个 Chrome/Edge Manifest V3 扩展。它只捕获当前页面的标题、链接、可读正文和时间候选，并通过桌面 App 提供的 Native Messaging host 写入本地收件箱。扩展不直接写磁盘、不读取历史记录或 Cookies，也不包含密钥和私人路径。

## 本地安装

1. 先启动桌面 App，在设置中安装网页剪藏 host；首次安装或首次连接时，浏览器会显示一次确认，这是浏览器授予扩展连接本机 App 的必要提示。
2. 打开 Chrome 或 Edge 的扩展管理页（Chrome：`chrome://extensions`；Edge：`edge://extensions`），打开“开发者模式”。
3. 点击“加载已解压的扩展”，选择本目录 `browser-extension`，不要选择压缩包内层目录。
4. 打开扩展“详情 → 扩展程序选项”，点击“测试首次连接”。成功后，在任意网页点击工具栏按钮，或右键选择“保存到最佳拍档”。

## 权限用途

- `activeTab`、`scripting`：只在用户点击按钮或右键菜单后读取当前页面。
- `storage`：只保存待发送项目的轻量索引和状态；完整 payload 保存在扩展本地 IndexedDB，以便稍后重试。
- `contextMenus`：提供“保存到最佳拍档”右键入口。
- `nativeMessaging`：连接桌面 App 的本地 host；不会允许扩展访问任意文件。

扩展没有 `history`、`cookies` 或文件系统权限，也没有后台抓取所有页面的功能。页面正文上限为 10 MiB，标题上限为 300 个字符。

## 连接失败与重试

如果桌面 App 未运行、host 尚未安装或连接中断，完整待发送 payload 会保存在扩展本地 IndexedDB，`chrome.storage.local` 只保留轻量索引/状态，不会静默丢失。回到扩展选项页点击“重试待发送收藏”；成功后对应项目会从本地待发送列表移除。卸载扩展会由浏览器清理其本地存储，卸载前请先重试或确认不再需要这些待发送项目。

## 卸载

在 Chrome/Edge 扩展管理页点击本扩展的“移除”并确认。卸载只移除扩展和浏览器侧待发送队列，不会删除桌面 App、大脑资料或 Native host；如需完全移除 host，请在桌面 App 设置中单独确认卸载。

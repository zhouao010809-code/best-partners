# 最佳拍档入门说明

欢迎使用最佳拍档。这套公开入门大脑已经准备好四个区域和一组普通语言规则，里面的资料与知识都是“示例”或“虚构”内容，不包含任何人的个人资料。

## 从一份资料开始

1. 把文件、粘贴文字或浏览器收藏放进 `01图书馆/小兆clipper` 收件箱。
2. 查看原文预览，确认后再归档；原文会保留，来源也可以回看。
3. 需要提炼时，让应用生成候选。候选不等于正式知识，检查后明确点击“确认入库”，才会进入 `02知识库`。
4. 要写文章或分享时使用已确认知识，先看最终预览，确认后再发送。

你可以先打开 `01图书馆/来自示例/2026-09/示例资料/示例资料.md`，再对照 `02知识库/示例主题/示例知识.md`，了解从原文到知识的过程。模板不会自动覆盖你后续编辑的文件。

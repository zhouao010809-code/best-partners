# 小兆大脑

个人 macOS 大脑管理 App。当前交付为 **独立只读桌面版**，不是完整个人 V1，也不提供 SaaS 服务。

## 当前可用范围

- 直接读取本地大脑文件夹，不要求 Obsidian 或其 Local REST 插件运行。
- 在 App 内浏览、搜索符合现有资料规范的 Markdown，查看结构问题。
- 左侧导航固定保留；窄窗口缩为图标栏。首页牌堆只展示未提炼资料。
- 定时检查文件并更新界面。正常情况下约 15 秒扫描一次，前台界面约 3 秒检查一次索引状态；不是实时文件监听，也不等于自动归档。
- 在设置页更换大脑文件夹，更换成功后 App 重启载入。

当前 **不会** 移动插件资料、修改原文、提炼知识、调用 DeepSeek、编辑或执行正式入库。未符合资料规范的原始剪藏可能显示为结构问题；自动收件归档属于后续阶段。

## 在这台 Mac 上使用

构建产物位于 `dist/desktop/小兆大脑-darwin-arm64/小兆大脑.app`，可以双击打开。当前仅针对 Apple Silicon Mac 构建；没有 DMG、公证或对外分发保证。

首次启动尝试读取之前保存的位置，否则使用当前用户主目录下的 `我的大脑`。位置无效时会弹出文件夹选择框。有效文件夹需要包含 `00大脑规则`、`01图书馆`、`02知识库`、`03大讲堂` 及当前规定的五份规则文件；不接受符号链接。

原始资料留在所选大脑文件夹中。可重建索引与设置保存在 App 的 `userData` 目录（正常为 `~/Library/Application Support/小兆大脑`），不写入大脑内容目录。设置位于 `config`，每个大脑按路径与目录身份使用独立的 `vaults/<hash>` 缓存；切换文件夹不会混用旧库索引，也不删除旧缓存。退出 App 会停止其本地服务。

本次验证全部使用临时测试库，**尚未完成正式大脑的真实资料验收**。不要将此阶段理解为完整的采集→提炼→入库工作流已完成。

## 开发与验证

需要 macOS arm64、Node.js 22.12+ 和 Xcode Command Line Tools。

```sh
npm ci
npm run electron
```

`electron` 会构建并启动独立桌面运行时；旧 `npm run dev`/`npm start` 仍属于 Local REST 兼容入口，需要其旧配置。

```sh
npm run verify
npm run test:native-read
npm run package:mac
npm run test:electron
```

`verify` 包含单元、集成、组件、类型检查与桌面构建。原生契约和真实桌面测试分别执行；桌面测试同时检查开发入口及先前生成的 `.app`，因此必须先打包。所有测试自行创建独立临时目录，测试根守卫在 Electron 初始化缓存之前同步执行。

浏览器端完整回归为 `npm run test:e2e`，首次需要 Playwright 浏览器。当前机器的浏览器回归使用已安装的 Chrome 运行，没有修改视觉基线。
